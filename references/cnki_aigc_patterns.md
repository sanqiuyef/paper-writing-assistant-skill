# 知网 AIGC 句式规则（经验整理）

> 来源：2026-11-14 转写的公开视频《知网又又又更新了》（谢师兄的读研日常，3:05）。视频转述的是个人实测与博主方法，**不是知网官方规则文档**。规则、阈值和检测结果都可能随平台更新变化；本文只用于改进写作质量，不用于规避检测。

## 背景

视频称知网个人 AIGC 检测服务于 **2026-10-24** 晚间例行升级：同一段“本章小结”，10 月 17 日测得 AI 特征 0，10 月 24 日未改一字再测，整段标红为 100%。作者据此复盘被标红的共同句式，并给出改写方法。该数字是单次个人实测，不能当作平台整体准确率。

## 被点名的四类特征

### 1. 动宾 + “了”扎堆

同一段连续出现多个“动词 + 了 + 宾语”：

- 研究了、发现了、提出了、明确了、揭示了
- 梳理了、界定了、对比分析了、论证了、给出了
- 构建了、设计了、采用了、验证了、总结了

视频例子：四句话里出现“梳理了、界定了、对比分析了、论证了、给出了”等十个动宾句式。改写不是删内容，而是换语序：

- `梳理了 X` → `对 X 进行梳理`
- `明确了 Y` → `将 Y 明确`
- `论证了 Z 的可行性` → `对 Z 的可行性进行论证`

对应检测：`check_ai_style.py` 的 `CNKI_VO_PILE`（WARN）。单段 ≥6 处，或单句 ≥3 处时提示。

### 2. `A的B与C` 型名词串

名词一个套一个，类似“葡萄串”：

- `灾后应急物流的概念内涵与场景特点`
- 升级版：`A的B与C的D`

改写靠“拆”：

- `本章系统梳理了灾后应急物流的概念内涵与场景特点`
  → `本章对灾后应急物流的概念内涵进行梳理，并总结其场景特点`
- `X 的两大核心特征是一和二是`
  → `X 的核心特征有两个，分别是一和二`

对应检测：`CNKI_NOUN_CHAIN`（WARN）。同一段出现 ≥2 处时提示。

### 3. 形容词 + 名词组合反复出现

如“重要意义、重要作用、核心特征、关键问题、显著提升、有效手段”等组合在文中反复出现。

改写：拆散组合，换成具体对象、条件或数据，不要只换同义词。

对应检测：`CNKI_ADJ_NOUN_REPEAT`（WARN）。

### 4. 句长与结构过于均匀

长句不拆、短句不并，整段句长和结构雷同。改写：长句拆短、短句合并，允许句长有变化。

对应检测：`CNKI_LONG_SENTENCE`（WARN，长句占比 ≥20% 时提示）与 `AI_UNIFORM_RHYTHM`（WARN）。

## 关键边界

1. 这些句式在社科论文里本来常见，人写的也会用；检测抓的是特征概率，规则一更新，标准就变，真人写的也可能被误判。
2. 本 skill 把这些规则定为 **WARN**，不是 FAIL；是否改、改到什么程度由作者结合学科惯例判断。
3. 改写必须保留术语、数据、公式、引用与结论方向；改写后用 `fact_integrity_check.py` 复核。
4. 不承诺降低任何平台的检测率；最终以学校/期刊指定平台的复检为准，并按政策披露 AI 使用。
5. 视频中提到的第三方“降 AIGC”服务与本 skill 无关；本 skill 只做本地检查与写作建议。
